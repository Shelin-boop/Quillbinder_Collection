The word list of the passphrase generator (Quillbinder 0.99.0, src/core/crypto/Passphrase.h)

eff_large_wordlist.txt: the EFF's large word list for passphrases, 7,776 English words, each after five dice digits.

  License: Creative Commons Attribution 3.0 (EFF's license for its site, https://www.eff.org/copyright); the text of
  the license is LICENSE.txt in this folder.
  Unchanged. Taken from Ubuntu 24.04's package diceware 0.10-2 (its file diceware/wordlists/wordlist_en_eff.txt,
  whose copyright file names the source and license above), because the session that added it could not reach eff.org.
  SHA-256: addd35536511597a02fa0a9ff1e5284677b8883b83e986e43f15a3db996b903e

The list exists in English only, so the generator gives English words in every language of the program.
