# Handwriting button icons

`handwriting-off.svg`, `handwriting-editor.svg`, `handwriting-inspector.svg` and `handwriting-both.svg`
(in `qbicons/actions/{16,22,32}` and `qbicons-dark/actions/{16,22,32}`) were drawn for Quillbinder in 0.99.0 by the
project itself (path data written by hand, with a small script, in the proportions and the one-color style of the
bundled Breeze icons). They are not copied or traced from any other icon set and are covered by the project's license
(Apache License 2.0). The light set uses the text color #232629, the dark set #eff0f1, as the Breeze files beside them.
