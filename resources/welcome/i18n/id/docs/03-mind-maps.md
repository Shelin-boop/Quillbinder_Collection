Setiap dokumen dan folder dapat memiliki **peta pikiran**: papan berisi catatan, garis, panah, warna, dan bentuk. Dokumen ini memilikinya.
**Cobalah:** klik tombol **Peta Pikiran** di inspektor, di antara Penanda dan Metadata (tombol bergaris bawah bila dokumen memiliki papan). Papan di dalamnya menunjukkan apa yang dapat dilakukan peta pikiran; **Zoom agar Pas** di atas papan menampilkan seluruhnya. **Buka di Jendela** di atas papan menampilkan papan yang sama di jendela besar dengan inspektor tersendiri.
- **Klik ganda** pada tempat kosong untuk catatan baru. Seret satu catatan ke catatan lain untuk menggambar garis; tahan **Alt** saat melepaskan untuk membuat panah.
- Klik kanan sebuah catatan untuk warna, bentuk, bingkai, dan ikonnya; klik kanan sebuah garis untuk panah, warna, dan ikon di tengahnya.
- **Menu > Catatan > Tambahkan Catatan ke Binder** mengubah catatan menjadi dokumen proyek ini.
- Papan dapat diekspor sebagai PDF, PNG, teks, OPML, atau berkas Scapple, dan berkas Scapple dapat dibaca ke dalam papan.
- **Bantuan > Bantuan Peta Pikiran** menjelaskannya dengan gambar dan memiliki papan latihan.
