Ein Manuskript kommt oft als Word- oder LibreOffice-Datei von einem Lektorat zurück, oder Sie arbeiten dort eine Zeit lang daran weiter. **Datei > Vergleichen und übertragen > Mit Datei vergleichen…** zeigt, worin sich eine solche Datei von Ihrem Projekt unterscheidet, und übernimmt die Seite, die Sie wählen.
- **Das Projekt aus der Datei aktualisieren**: Die Änderungen gehen in Ihre Dokumente. Jedes geänderte Dokument erhält zuvor eine Momentaufnahme, sodass Sie jederzeit zurückgehen können.
- **Die Datei aus dem Projekt aktualisieren**: {{APP}} schreibt eine Kopie der Datei daneben. In einer Word-Kopie ist jede Änderung eine verfolgte Änderung, die Sie in Word oder LibreOffice annehmen oder ablehnen.
- **Nach Kapitel** listet die Dokumente mit ihren Änderungen auf, jeweils mit einem Kästchen; **Schritt für Schritt** zeigt jeweils eine Änderung.
- Grüner Text kommt hinzu, roter durchgestrichener Text fällt weg, blauer Text übernimmt Fett, Kursiv oder Unterstrichen der anderen Seite.
Die Datei wird mit dem verglichen, was **Kompilieren** aus dem Projekt macht. Kompilieren Sie also einmal und bewahren Sie die Datei auf, die Sie weitergeben.
