Jedes Dokument und jeder Ordner kann eine **Mindmap** haben: eine Fläche mit Notizen, Linien, Pfeilen, Farben und Formen. Dieses Dokument hat eine.
**Probieren Sie es aus:** Klicken Sie im Inspektor auf die Schaltfläche **Mindmap**, zwischen Lesezeichen und Metadaten (die Schaltfläche ist unterstrichen, wenn das Dokument eine Fläche hat). Die Fläche zeigt, was Mindmaps können; **An Fenster anpassen** über der Fläche zeigt sie ganz. **In Fenster öffnen** über der Fläche zeigt dieselbe Fläche in einem großen Fenster mit einem eigenen Inspektor.
- **Doppelklicken** Sie auf eine leere Stelle für eine neue Notiz. Ziehen Sie eine Notiz auf eine andere, um eine Linie zu zeichnen; halten Sie beim Loslassen **Alt** gedrückt, um einen Pfeil zu erhalten.
- Mit einem Rechtsklick auf eine Notiz erreichen Sie ihre Farben, Form, Rahmen und Symbole; mit einem Rechtsklick auf eine Linie ihre Pfeile, ihre Farbe und ein Symbol in der Mitte.
- **Menü > Notizen > Notizen zum Binder hinzufügen** macht aus Notizen Dokumente dieses Projekts.
- Eine Fläche lässt sich als PDF, PNG, Text, OPML oder Scapple-Datei exportieren, und Scapple-Dateien lassen sich in eine Fläche einlesen.
- **Hilfe > Mindmap-Hilfe** erklärt alles mit Bildern und bietet eine Übungsfläche.
