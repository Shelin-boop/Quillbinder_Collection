{{APP}} lit et écrit des projets Scrivener 3, si bien que vous pouvez passer d'un logiciel à l'autre.
- **Importer** : **Fichier > Importer > Projet Scrivener…** crée un projet {{APP}} à partir d'un projet Scrivener 3 ou 2. Le classeur, les textes, les synopsis, les notes, les libellés, les statuts, les mots-clés, les instantanés, les commentaires, les notes de bas de page, les fichiers de recherche et les collections suivent. Le projet Scrivener est seulement lu.
- **Travailler au format Scrivener** : ouvrez le fichier *.scrivx* à l'intérieur d'un dossier *.scriv* avec **Fichier > Ouvrir un projet…** et choisissez **Travailler au format Scrivener**. {{APP}} enregistre alors directement dans le *.scriv*, si bien que vous pouvez poursuivre plus tard dans Scrivener, par exemple sur un autre ordinateur. Fermez le projet dans un logiciel avant de l'ouvrir dans l'autre.
- **Fichier > Enregistrer sous…** enregistre un projet dans l'autre format (ou sous un autre nom), et **Fichier > Exporter** enregistre une copie qui laisse tel quel le projet sur lequel vous travaillez.
- Un projet {{APP}} à lui seul conserve chaque document sous forme de fichier texte brut (Markdown, ou RTF si vous préférez), lisible avec n'importe quel éditeur.
