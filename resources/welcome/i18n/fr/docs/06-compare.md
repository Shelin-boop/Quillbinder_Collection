Un manuscrit revient souvent d'un éditeur sous forme de fichier Word ou LibreOffice, ou bien vous continuez à y travailler un moment. **Fichier > Comparer et transférer > Comparer avec un fichier…** montre ce qui diffère entre un tel fichier et votre projet, et reprend le côté que vous choisissez.
- **Mettre à jour le projet à partir du fichier** : les modifications passent dans vos documents. Chaque document modifié reçoit d'abord un instantané, de sorte que vous pouvez toujours revenir en arrière.
- **Mettre à jour le fichier à partir du projet** : {{APP}} écrit une copie du fichier à côté de l'original. Dans une copie Word, chaque modification est une modification suivie que vous acceptez ou refusez dans Word ou LibreOffice.
- **Par chapitre** énumère les documents avec leurs modifications, chacun avec une case à cocher ; **Étape par étape** montre une modification à la fois.
- Le texte vert est ajouté, le texte rouge barré est supprimé, le texte bleu reçoit le gras, l'italique ou le soulignement de l'autre côté.
Le fichier est comparé à ce que **Compiler** produit à partir du projet : compilez donc une fois et conservez le fichier que vous envoyez.
