Un manoscritto spesso torna da un editor come file Word o LibreOffice, oppure ci lavori ancora per un po' lì. **File > Confronta e trasferisci > Confronta con file…** mostra cosa differisce tra un file simile e il tuo progetto e prende il lato che scegli.
- **Aggiorna il progetto dal file**: le modifiche vanno nei tuoi documenti. Ogni documento modificato riceve prima un'istantanea, così puoi sempre tornare indietro.
- **Aggiorna il file dal progetto**: {{APP}} scrive una copia del file accanto ad esso. In una copia Word, ogni modifica è una modifica registrata che accetti o rifiuti in Word o LibreOffice.
- **Per capitolo** elenca i documenti con le loro modifiche, ciascuno con una casella; **Passo per passo** mostra una modifica alla volta.
- Il testo verde entra, il testo rosso barrato esce, il testo blu riceve il grassetto, il corsivo o la sottolineatura dell'altro lato.
Il file viene confrontato con ciò che **Compila** ricava dal progetto, quindi compila una volta e conserva il file che invii.
