Um manuscrito muitas vezes volta de um editor como arquivo do Word ou do LibreOffice, ou você continua trabalhando nele lá por um tempo. **Arquivo > Comparar e transferir > Comparar com arquivo…** mostra o que difere entre esse arquivo e o seu projeto e assume o lado que você escolher.
- **Atualizar o projeto a partir do arquivo**: as alterações vão para os seus documentos. Cada documento alterado recebe antes um instantâneo, para que você sempre possa voltar.
- **Atualizar o arquivo a partir do projeto**: o {{APP}} grava uma cópia do arquivo ao lado dele. Em uma cópia do Word, cada alteração é uma alteração rastreada que você aceita ou rejeita no Word ou no LibreOffice.
- **Por capítulo** lista os documentos com as suas alterações, cada um com uma caixa de seleção; **Passo a passo** mostra uma alteração de cada vez.
- O texto verde entra, o texto vermelho riscado sai, o texto azul recebe o negrito, o itálico ou o sublinhado do outro lado.
O arquivo é comparado com o que o **Compilar** faz do projeto, então compile uma vez e guarde o arquivo que você enviar.
