{{APP}} lee y escribe proyectos de Scrivener 3, de modo que puedes pasar de un programa a otro.
- **Importar**: **Archivo > Importar > Proyecto de Scrivener…** crea un proyecto de {{APP}} a partir de un proyecto de Scrivener 3 o 2. El archivador, los textos, las sinopsis, las notas, las etiquetas, el estado, las palabras clave, las instantáneas, los comentarios, las notas al pie, los archivos de investigación y las colecciones se vienen contigo. El proyecto de Scrivener solo se lee.
- **Trabajar en formato Scrivener**: abre el archivo *.scrivx* que está dentro de una carpeta *.scriv* con **Archivo > Abrir proyecto…** y elige **Trabajar en formato Scrivener**. Entonces {{APP}} guarda directamente en el *.scriv*, de modo que luego puedes seguir en Scrivener, por ejemplo en otro equipo. Cierra el proyecto en un programa antes de abrirlo en el otro.
- **Archivo > Guardar como…** guarda un proyecto en el otro formato (o con otro nombre), y **Archivo > Exportar** guarda una copia que deja el proyecto en el que trabajas tal como está.
- Un proyecto propio de {{APP}} guarda cada documento como un archivo de texto sin formato (Markdown, o RTF si lo prefieres), legible con cualquier editor.
