# Pictures of the program

`main-window.png` (shown in the top-level README): the main window of Quillbinder, English, standard theme, with the
program's own welcome project (`resources/welcome`, written for Quillbinder). It is a screenshot of the program, made
by a scripted run of the test suite `qb_v0930e_tests`:

    QB_README_SHOT=docs/images/main-window.png xvfb-run -a build/tests/qb_v0930e_tests /tmp/shots

The picture holds no text, picture or project of a person, and nothing of Scrivener or Scapple.
